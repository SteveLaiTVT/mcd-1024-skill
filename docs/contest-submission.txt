项目简介：饭点选套餐的浏览器扩展，支持 1–4 人、食量、人均预算与近期主食避开。直接使用麦当劳 MCP 查门店营业情况、菜单、可领券与持有券，逐份比较官方整单报价，让圆盘揭晓预算内完整套餐。DeepSeek V4.1 Flash 提供推荐 Agent、优化 Agent 或最多两轮协作，结合明确口味反馈、用户自定义 prompt、城市天气、月份及节假日，从已核价候选中个性化选择；旧偏好逐渐减弱，可查看和忘掉。用户可分别选择在本机扩展长期保存麦当劳 Token、DeepSeek key 和反馈记忆，刷新不自动请求 AI；地址、券包和订单不持久保存。用餐雷达主动读取完成订单，展示全年/近12周热力图，未返回日期标为未知。无需业务后端，GitHub 提供源码、扩展 ZIP 与静态体验；体验价为历史样本，示例雷达为虚构。69 项 JavaScript 与 23 项 Python 测试通过，Chrome 已实测凭证恢复、实时核价和真实双 Agent 推荐。WorkBuddy 实际参与赛事调研、项目初始化与发布配套，开发上下文见 workbuddy.md。领取券需明确确认，项目不下单或付款；独立开发，非麦当劳官方产品。
