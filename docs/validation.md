## 2.3.0 AI 饭搭子与明确偏好记忆

2026-10-10，69 项 JavaScript 测试全部通过。新增验证覆盖：

- 只有主动反馈才学习，同模板同日覆盖、90 天偏好衰减、记忆开关、查看 / 删除与跨页撤销；揭晓不记消费，记录不包含账号 / 订单 / 地址。
- 单 Agent 和最多两轮协作、优化 Agent 改选、自定义 prompt 限定为数据、每一轮 JSON 校验、拒绝额外价格 / 未知 ID / 重复 / 无证据理由；省钱目标不能越过当前池最低价，取消或旧报价不能继续下一轮。
- DeepSeek 固定官方 URL / Flash 模型 / 非思考模式 / JSON Output / 输出上限；不带 Cookie 或工具，不重试付费调用；鉴权、余额、限流、网络、非 JSON / 截断 / 错误模型、超时和中止。
- DeepSeek key 与麦当劳隔离，默认不保存，刷新恢复配置但不调用模型；取消保存保留本页可用，主动停用即时关闭客户端；保存 / 删除失败有可见状态，另一页撤销或陈旧启动读不能恢复旧 key。
- 同名天气城市需明确选择，校验观测时效和摄氏单位、本页缓存；温度未知不猜，热辣不当热饮；天气失败保留本地推荐。2026 调休日期、跨 UTC 中国日期、未知年份不造假期。
